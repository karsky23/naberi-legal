ОБНОВЛЕНИЕ САЙТА NABERI LEGAL

1. Распакуйте архив.
2. В репозитории naberi-legal нажмите Add file → Upload files.
3. Перетащите всё содержимое папки naberi-legal-multilang-v2.
4. Убедитесь, что загружаются:
   index.html
   styles.css
   delete-account.html
   ru/index.html
   kk/index.html
   en/index.html
   uk/index.html
   uz/index.html
5. Нажмите Commit changes.
6. Через 1-2 минуты откройте:
   https://karsky23.github.io/naberi-legal/
7. Нажмите Ctrl+F5.

Теперь по умолчанию открывается русская политика, а сверху есть аккуратные кнопки выбора языка.
